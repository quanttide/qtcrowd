# 量潮众包官网 — 设计

## 定位

量潮科技把销售工作众包出去，面向外部渠道与代理，按量潮标准结算。

站点只做信息展示：**以接单人（外部渠道 / 代理）为中心**，站在第二人称说明"你能得到什么、要做什么、怎么开始、怎么相信"，不是交易平台。

## 页面

- 首页 `/`：接单人价值主张（你能得到什么）+ 可接任务清单（你可以接这些活）+ 怎么开始 + 联系
- 任务清单 `/post`：量潮在发什么（需求方 + 当前发布的销售众包任务 + 按什么结算）
- 成为伙伴 `/take`：接单人深潜——你能得到什么、你要做什么、怎么开始、怎么相信

## 风格约束

- 克制 / 文字优先 / 留白
- 颜色仅黑、白、灰；无动画、无渐变、无卡片阴影
