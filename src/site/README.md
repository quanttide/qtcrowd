# 量潮众包官网（qtcrowd-site）

信息展示站：量潮科技自营发销售众包（渠道/代理销售），站点只做说明展示，不是交易平台。

## 技术栈

- React 19 + TypeScript
- Vite 6

## 页面

- 首页 `/`：定位、量潮科技在发什么销售众包、参与方式、联系
- 发单 `/post`：量潮科技发什么、结算方式
- 参与 `/take`：外部渠道与代理如何参与、平台原则

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```
