# 量潮众包官网（qtcrowd-site）

信息展示站：量潮科技自营发销售众包（渠道/代理销售），**以接单人为中心**，站点只做说明展示，不是交易平台。

## 技术栈

- React 19 + TypeScript
- Vite 6

## 页面

- 首页 `/`：接单人价值主张、可接任务清单、怎么开始、联系
- 任务清单 `/post`：量潮在发什么（需求方 + 任务 + 结算方式）
- 成为伙伴 `/take`：成为接单伙伴——你能得到什么、要做什么、怎么开始、怎么相信

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```
