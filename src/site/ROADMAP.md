# ROADMAP

量潮众包官网（qtcrowd-site），信息展示站。

## 目标

展示量潮科技自营销售众包的定位与参与方式，站点只做信息展示。

## 当前状态

- 首页：定位 + 量潮科技在发什么销售众包 + 参与方式 + 联系
- 发单页：量潮科技发什么、结算方式
- 参与页：外部渠道与代理如何参与、平台原则
- 数据：`src/data/tasks.ts` 销售众包任务类型静态清单

---

## 阶段 1：内容补齐

| 任务 | 说明 |
|------|------|
| 补全任务类型 | 按实际在发的销售众包完善条目与结算标准 |
| 联系信息 | 补全邮件 / 联系方式，核对 GitHub 链接 |
