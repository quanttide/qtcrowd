# ROADMAP

量潮众包官网（qtcrowd-site）。

## 目标

实现众包平台的公开入口：展示「标准交易市场」定位，为需求方与执行方提供发单、接单的流程说明，并公开与 qtdata 的筛选导流协同。核心问题：**需求方为什么在这里发单、执行方为什么在这里接单？**

## 当前状态

- 首页：Hero + 交易方式入口 + 标准任务清单 + 与 qtdata 协同 + 联系
- 发单页：流程说明 + 标准任务类型
- 接单页：流程说明 + 平台原则 + 当前状态
- 数据：`src/data/tasks.ts` 静态标准任务清单
