# qtcrowd

量潮众包：通用众包平台，标准交易市场——需求拆解为标准任务，执行方按量潮标准交付，验收准则兜底。

核心协同：用 qtcrowd 给 qtdata 筛选导流，达标执行方进入 qtdata 认证供应商池。

## 代码

| 路径 | 说明 |
|------|------|
| `src/site` | 众包官网（React 19 + Vite，见 [site README](./src/site/README.md)） |

## 开发

```bash
cd src/site && npm install && npm run dev
```

## 构建

```bash
cd src/site && npm run build
```
